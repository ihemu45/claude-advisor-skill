about dealgrep

dealgrep is a small, open deals radar: an automated agent checks public deal feeds and searches the web every hour, then publishes what it finds as a fast static site.

what it is#

Every hour a scheduled job collects deals from public sources (Slickdeals, deal subreddits, the Best Buy API) and, when an API key is configured, asks Claude to research live deals at Amazon, Best Buy, Target, Walmart and other large US retailers using web search. Everything is normalised into one data file: store, category, price, list price, discount, coupon code and when the deal was first seen. The site is plain HTML that reads that file, so it loads fast and works without an account.

Pick a category to see its offers, then type an item name to filter down to that item and compare the lowest price per store. Coupon codes are shown right on the card with a copy button.

why#

Deal sites are noisy and store sale pages are hard to compare. dealgrep does the boring part, checking many places every hour, and keeps the result in one searchable list with a plain heat score so the best offers float to the top. It is also a working example of running an hourly research agent for free on GitHub Actions and GitHub Pages.

who runs it#

dealgrep is maintained by ihemu45 on GitHub. The code, the agent and this site live in one public repository, so you can read exactly how deals are collected and scored, or run your own copy.

contact#

  • Found a wrong price, a dead link or a miscategorised deal? Open an issue with the deal title and store.
  • Want a source added? Any public RSS or JSON feed works. See adding a source in the docs, then open an issue or a pull request.
  • Something else? Issues are the quickest way to reach the maintainer.

disclaimer#

Prices, stock and coupon codes change by the minute. dealgrep shows what a source reported at a point in time and may lag by up to an hour. Always check the price on the store page before you buy. dealgrep has no affiliate relationship with any store listed and earns nothing from clicks.

Store names and logos belong to their owners. Deal data is aggregated from public feeds and is reproduced for information only.
