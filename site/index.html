how it works

read the docs →
01 · collect

Public deal feeds, every hour

A GitHub Actions job runs on a schedule and pulls Slickdeals, deal subreddits and the Best Buy API. Nothing is scraped from store pages.

02 · research

Claude searches the web

With an API key configured, Claude researches a rotating slice of categories using live web search and reports only deals it could confirm, with store, price and code.

03 · publish

Normalise, score, deploy

Deals are de-duplicated across sources, categorised, given a heat score and written to JSON. The static site you are reading is redeployed with the fresh data.
